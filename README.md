# vpn-server-setup

Пару месяцев назад понял, что хочу свой VPN — не платить за чужие сервисы и знать, куда утекают мои данные. За выходные разобрался и написал скрипты, которые делают всё автоматом. Может кому-то пригодится.

Что тут:
- **WireGuard** — поставил, потому что он быстрый и конфиги занимают 10 строк, а не 100 как у OpenVPN
- **OpenVPN** — тоже добавил, на всякий случай, некоторые клиенты его лучше держат
- **UFW** — фаервол, без него сервер как дом без дверей
- **SSH-харднинг** — закрыл дыры, потому что brute-force на SSH это первое, что приходит в голову ботам

---

## Как запустить (буквально 3 команды)

Если лень вникать — просто копируй по очереди:

```bash
chmod +x scripts/wireguard-setup.sh
sudo ./scripts/wireguard-setup.sh
```

Скрипт сам скачает WireGuard, сгенерит ключи, поднимет интерфейс и выдаст QR-код для телефона. Магия, но работает.

Фаервол:
```bash
chmod +x scripts/ufw-setup.sh
sudo ./scripts/ufw-setup.sh
```

SSH (опционально, но советую):
```bash
chmod +x scripts/ssh-hardening.sh
sudo ./scripts/ssh-hardening.sh
```

OpenVPN я пока не завернул в автоматический скрипт — если нужен, пишите, добавлю. Пока что конфиг ручной в папке `configs/openvpn/`.

## Что нужно

- Сервер на Ubuntu/Debian (я тестил на Ubuntu 22.04). Hetzner / Timeweb / Beget — берите кого угодно, от 200р/мес.
- Root (sudo). Без рута VPN не поднимешь, нужно ковырять ядро.
- Открытый UDP-порт 51820. Некоторые хостинги закрывают его по умолчанию — откройте в панели управления.

## Почему я это сделал

Платные VPN типа NordVPN — это нормально, но:
1. Платишь каждый месяц
2. Не знаешь, что они там логируют
3. Скорость просаживается на общих серверах

Свой сервер стоит 200-400р/мес, скорость — что даёт твой тариф, логов нет (если сам не включишь). Плюс разобрался как работает сеть, пригодилось в универе.

## Если что-то сломалось

- **WireGuard не стартует**: проверь `sudo wg show` — если пусто, скорее всего порт 51820 закрыт на хостинге
- **Нет интернета через VPN**: убедись что включён IP forwarding (`sysctl net.ipv4.ip_forward` должен выдать `1`)
- **UFW заблочил SSH**: случай нереальный если запускал `ufw-setup.sh` из репо, но на всякий — не закрывай текущую сессию терминала до проверки

Пишите в Issues, если что — разберёмся.
